# Sibionics Reading Recovery, Reading Age, and Sibionics 1

**Goal:** Make persisted Sibionics readings visible in the existing graph/statistics path, display JugglucoNG-style reading age in peripheral details, and support both Sibionics 1 protocol variants through the current CGM pipeline.

**Constraints:** Keep the Sibionics 2 V120 BLE protocol, stock V116A correction, and existing nonzero calibrated results unchanged. Correct the zero-valued reading creation path for Sibionics sensors as part of the history fix. Scope persisted reading repair to missing, non-manual readings from the active Sibionics sensor. Preserve real timestamps, indexes, deduplication, and existing calibration settings. Sibionics 1 EU uses V120/V116A with its own session key; Chinese Sibionics 1 uses plaintext AA55/V115G. Persist explicit sensor variant and negotiated protocol; never infer EU Sibionics 1 vs Sibionics 2 from the V120 marker. Do not expose Sibionics 2-only reset/auto-reset to Sibionics 1. Retain GPL attribution for Juggluco-derived implementation/fixtures. Do not run GitHub Actions, archive, or TestFlight.
